# 카카오톡 3탭 콘텐츠 업로더 프로토타입

카카오톡 3탭 피드에서 콘텐츠 작성 화면으로 이어지는 모바일 클릭 프로토타입입니다.

## 주요 인터랙션

- 피드의 `+` 버튼으로 작성 화면 진입
- 콘텐츠 직접 입력 및 텍스트 선택 메뉴
- 내용 기반 추천 토픽 단일 선택
- 선택한 토픽 수정 및 삭제
- 사진, 위치, 링크, 투표, 멘션, 이모티콘 옵션
- 발행 옵션과 완료 화면

## 로컬 실행

```bash
npm install
npm run dev
```

GitHub Pages용 정적 빌드는 `npm run build:pages`로 생성됩니다.
